# 🧮 NUMBER EQUATION

เกมฝึกคิดเลขโดยการวางสมการบนกระดาน  
เล่นได้ทั้งแบบฝึกซ้อมและแข่งขัน 10 รอบ พร้อมระบบ Combo, Event สุ่ม และ Leaderboard ออนไลน์ (Firebase)

## 🎮 วิธีการเล่น
- คุณจะได้รับไพ่ตัวเลข 6 ใบ และเครื่องหมาย (+,-,×,÷) สูงสุด 4 ใบ
- เลือกตำแหน่งของเครื่องหมาย `=` บนกระดาน 8 ช่อง
- วางตัวเลขและเครื่องหมายให้เกิดสมการที่ถูกต้อง (เช่น `6 + 7 = 13`)
- ถ้าถูกต้อง จะได้คะแนนตามแต้มไพ่ + โบนัสพิเศษ
- ทำสมการติดต่อกันเพื่อเพิ่ม Combo คะแนนจะทวีคูณ
- ทุกรอบจะมีอีเวนท์สุ่มและเป้าหมายที่แตกต่างกัน
